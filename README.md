# AeroNova — Explora la aviación

AeroNova es un sitio web educativo interactivo sobre aviación, creado con HTML, CSS y JavaScript.

## Funcionalidades
- Navegación por cuatro secciones: Inicio, Explorar, Simulador y Quiz.
- Diseño responsive para computadoras y celulares.
- Formulario con validación básica.
- Calculadora ilustrativa de presupuesto de viaje.
- Quiz de cinco preguntas con puntuación y retroalimentación.
- Animaciones, tarjetas, estados hover y menú móvil.

## Archivos
- `index.html`: estructura y contenido.
- `style.css`: diseño, animaciones y adaptación responsive.
- `script.js`: navegación e interacciones.

## Cómo ejecutar
Abre `index.html` en tu navegador o utiliza la extensión Live Server de Visual Studio Code.

## Publicar con GitHub Pages
1. Crea un repositorio público llamado `aeronova`.
2. Sube `index.html`, `style.css`, `script.js` y `README.md` a la raíz del repositorio.
3. En GitHub, entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`, y pulsa **Save**.
6. Espera a que GitHub Pages publique el sitio.

La URL normalmente será `https://TU-USUARIO.github.io/aeronova/`.
